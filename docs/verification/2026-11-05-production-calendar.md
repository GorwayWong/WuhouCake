# 糕点师日历与订单卡片验证（2026-11-05）

## 实现范围

- 沿用 `orderAccess.productionView` 判定制作视图，不按岗位名分支；没有变更岗位授权、后端接口、数据库或订单详情。
- 制作列表按北京时间准确出品分钟分组，同分钟合并、跨日显示日期、未安排置后，不借用取货时间。前厅仍按取货半小时分组，日历归日不变。
- 制作卡片仅突出首项商品的尺寸和蛋糕胚；非蛋糕显示规格。空值标记待确认，历史字符串、数组、对象可读展示且不覆写。保留项数、件数、其他商品提示、订单号、制作状态、最新备注和详情链接，不重复显示取货或出品时间。
- 缩略图先匹配首项商品，再回退未绑定商品的整单图片；仅有其他商品图片时显示无款式图。沿用图片加载、失败和资源释放行为。
- 制作视图的默认折叠统计只保留订单总数与原备胚统计。总数从未筛选列表计算，排除取消和两种删除标记，包含完成订单。列表标题也不计入删除订单。
- 制作视图不挂载付款统计，不请求 `payment-summary`。独立授予金额权限时，付款筛选和付款标识仍按权限显示；具备业务资料权限的兼岗和店长账号继续使用业务视图。
- 代码已移除重复页面标题和年月标题，本次保留现有实现。

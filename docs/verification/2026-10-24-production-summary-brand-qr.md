# 生胚状态、蛋糕胚汇总与品牌二维码验证

## 变更

- PROCESSING 的订单中文状态统一为“生胚中”，同步流程条、回退提示、共享状态映射及经营报表。商品 IN_PROGRESS 含义不变。

- PASS：前端构建；新增尺寸小计测试及状态、回退相关测试。
- GAP：前端全量 87 项中 86 项通过；既有商品类型测试仍预期旧类型集合，与本次修改无关，未调整。
- PASS：后端单元测试与 ArchUnit；独立 PostgreSQL schema、Redis 命名空间的 OrderIT 验证尺寸口味分组、数量累加、小数尺寸、原味兜底、奶油不混入胚口味、包含已完成订单，以及排除取消单、移除商品、其他出货日期及非蛋糕商品。

- PASS：浏览器模拟重置及员工切换，图片和入口链接同步更新；页面预览 data URL 与下载 href 完全相同。
- PASS：jsQR 解码实际浏览器生成的三张带 logo 图片，分别准确还原原入口、重置后入口及另一员工入口，测试 URL 使用 HTTPS 域名和 64 位 token。

# 草稿与编辑审计的已知问题

日期：2026-11-08。以下问题已在本地模拟接口浏览器中复现。当前进度发布保留这些问题，不代表已经修复。

1. **P1：退出失败时草稿图片可能丢失。** `useOrderDraft.clear()` 在服务端退出成功前异步删除图片；退出失败恢复草稿记录时，图片文件可能已被删除。应将图片物理清理延后到确认退出成功，并验证失败回滚同时保留文本和图片。
2. **P1：编辑暂存图片跨标签页隔离不足。** 同一员工在两个标签页编辑同一订单，重新读取暂存后可在一个标签页移除另一个会话的图片；原会话保存时可能将空队列当作成功。应按编辑会话限制操作，提交前核对预期文件，缺失时明确报错。
3. **P2：未选图的普通编辑依赖图片存储清理。** IndexedDB 写入失败时，没有新选图片的资料编辑也无法取消。没有本会话图片时不应执行不必要的清理。

本次审计仅操作模拟数据，没有更改线上订单。相关代码为 `frontend/src/useOrderDraft.ts`、`App.tsx`、`OrderImages.tsx`、`OrderDetail.tsx` 和 `draftImages.ts`。常规测试通过不能替代上述失败及并发场景验证。

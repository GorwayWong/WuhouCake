# 周历付款明细与返回导航验证

## 实现

- 付款标记汇总、出货已付款和出货未付款均进入独立分页列表，每页 10 条，再进入原订单详情。
- 列表记录返回来源、日期、类别、页码；详情和日志沿用来源返回列表，列表返回原工作台。周历视图和筛选由现有状态维护，滚动位置按路由恢复。
- 当天付款使用北京时间付款标记日，包含取消但仍已付款的订单；出货分组排除取消。金额按整单计算。员工业绩付款列明确为订单总额。

## 验证结果

- PASS：Maven 全模块单元测试及 ArchUnit。
- PASS：OrderIT 中出货付款汇总及分页测试，使用独立 PostgreSQL schema 和 Redis 命名空间。覆盖整单金额、空金额与零元、多商品不重复、取消与历史下单、未来出货、北京时间边界、分页及付款撤销后页码收敛。
- PASS：HTTP Web 测试覆盖未认证、缺少金额权限、下单时间裁剪，以及保留金额和付款时间。
- PASS：前端构建；付款路由新增测试通过，包括列表来源、页码、详情/日志返回、无效日期及外部来源拒绝。
- GAP：前端全量测试 86 项通过 85 项。既有商品类型测试仍预期“蛋糕、甜甜圈、纸杯蛋糕、其他茶歇”，当前实现为“蛋糕、面包、甜甜圈、纸杯蛋糕、饮品”；本次未调整该测试或商品类型实现。
- PASS：内置浏览器通过临时模拟 API 页面验证三个入口、独立列表、下一页、进入详情、返回保留第二页、逐级返回原选中日期。列表在滚动 452 像素处进入详情，返回后仍为 452 像素。此检查使用模拟数据；真实查询条件由上述数据库集成验证覆盖。
- NOT RUN：浏览器中真实服务的付款更正、SSE 实际推送、复杂筛选恢复的端到端验收。代码沿用 workbench 查询失效，新增列表使用同一查询前缀。

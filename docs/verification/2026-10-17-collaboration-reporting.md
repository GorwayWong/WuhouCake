日期：2026-10-17。本文记录在八项审计修复基础上，按补充业务重点完成的优化。所有验收使用本地隔离 PostgreSQL、Redis 和合成员工；示例电话、地址已替换，未调用外部识别服务，未使用生产数据。

## 结果与业务口径

| 重点 | 当前行为 |
| --- | --- |
| 全员协作 | 订单变化同事务记录操作者、时间及适用的修改前后值，提交后通过 SSE 推送。站内“订单更新”显示订单号、动作和查看入口，合并同一订单，保留本次在线期间最近 20 张订单。包含本人操作，退出或切换账号清空。 |
| 轻量并发保护 | 服务端严格校验 expectedVersion。资料和商品编辑收到新版本后保留草稿、暂停保存；员工核对最新资料并明确继续后，再次保存实际修改字段。备注和图片不递增订单版本，但仍通知并刷新。 |
| 订单文字识别 | 提取客户、会员、交接、金额及商品具体字段；不确定内容留空或明确标记默认，手动内容保留，支持逐项采用与撤销。空白候选可折叠显示，缺少数量时提醒补填。 |
| 示例模板 | 日期、8 寸尺寸、电话、地址及芒果/脆啵啵/奥利奥夹馅进入对应字段。默认内胚为原味；空价格、商品名称、交接时间保持为空。订购须知中的运费、其他尺寸、餐具人数与可选夹馅不成为本单事实。 |
| 日期与筛选 | 默认按收货日期，可选北京时间录单日期；界面结束日期包含当天，接口使用右开区间。状态、付款、交接、数字尺寸、员工、未归属及关键词共用同一筛选口径。默认排除取消单，可明确包含或只选取消单。 |
| 尺寸统计 | 按有效蛋糕商品 quantity 累加；8、8.0、8.00 及可辨认的旧“8寸”合并。缺失、结构异常、非正数或不能表示为两位小数的旧尺寸进入待核对组，不导致查询失败。各尺寸组内订单去重，混合尺寸订单的组间订单数不可相加。 |
| 员工业绩 | 按下单员工账号分组，改名不拆组，归档员工保留历史，未归属独立成组。显示订单数、匹配商品件数、蛋糕数、已填写约定金额、标记已付款/未付款金额和未填金额订单数。员工名称使用最近录单的归属快照，创建人与实际操作人另留记录。 |
| 导出 | XLSX 含统计、尺寸统计、员工业绩、订单明细、商品明细五表，表头冻结并可筛选。商品明细分列尺寸、奶油、内胚、夹馅、祝福语、要求、报价。所有表使用同一条件和数据库可重复读快照，导出不新增业务日志、版本或推送。 |

金额是整单约定金额。尺寸筛选只改变匹配商品范围，不把整单金额分摊给某一尺寸。付款由员工手动标记，因此“标记已付款约定金额”不代表实际收款流水。未填金额独立计数，空值与零元保持区别。

## 采用的产品做法

| 参考 | 本项目的决定 | 原因 |
| --- | --- | --- |
| Shopify 区分销售归属员工与处理订单员工，可按员工衡量表现。[官方说明](https://help.shopify.com/en/manual/sell-in-person/shopify-pos/order-management/add-staff-to-sale) | 保留 creditedEmployee 与 createdBy/日志操作者的独立身份。 | 前台可代同事录单，业绩归属不能取代操作审计。 |
| Shopify 提供商品、变体、员工等维度的销售报告。[官方说明](https://help.shopify.com/en/manual/reports-and-analytics/shopify-reports/report-types/default-reports/retail-sales-reports) | 提供尺寸和员工业绩汇总，并能进入筛选后的明细。 | 店主需要从总数核对到具体订单；商品数量与订单数分别表达。 |
| Square 的报告示例通过时间、订单条件及商品明细构造汇总。[官方说明](https://developer.squareup.com/docs/commerce/scenarios/simple-sales-report) | 将查询、汇总、分组和导出绑定到同一业务条件及读取快照。 | 减少列表与导出数字不一致，也避免商品联表重复累加整单金额。 |

上表右两列是结合本店流程作出的实现选择，不代表与参考系统的账务、佣金或退款功能等价。

## 已确认范围与边界

- 已确认本阶段只做员工业绩汇总及可核对明细，不计算提成，也不预设提成比例或计提规则。
- 已确认附件纸单作为字段和导出单据参考，本阶段不做照片 OCR。手写年份、尺寸高度、员工姓名和付款信息存在歧义时应人工确认。
- 推送为当前单实例应用的在线站内更新，断线后 REST 同步最新数据；未新增微信、短信、离线系统通知或跨实例消息服务。完整历史以持久化操作日志为准。
- 查询最多 366 天；经营导出最多 10,000 单、50,000 行商品。订单商品描述与商品明细文本各限 8 MiB，单格最多 32767 字符；超限明确报错，不静默截断。
- 数据库新增 V9 迁移以规范尺寸统计并索引录单时间，既有 V1—V8 迁移未改写。本报告仅记录本地验收，不表示已部署生产环境。

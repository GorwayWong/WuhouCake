# 套餐管理验证记录

日期：2026-10-25。依据当前工作区验证，未提交 Git。工作区原有未提交改动保留。

## 实现范围

首页导航新增仅 MANAGER 岗位可见的“套餐管理”，提供名称搜索、分页、新建、编辑保存和删除。员工新建订单中只保留选用套餐；按份追加独立商品，不合并同名商品，不带入价格、图片、客户或整单金额。空规格可以保存，已填尺寸按现有规则校验。

服务端区分选用和维护资格，有效套餐名称唯一，修改与删除校验版本。创建使用 Idempotency-Key；请求结果未确认时保留并锁住草稿，确认原操作后才继续。完整变更快照与通用审计同事务保存，审计失败时套餐变更及快照均回滚。

V18 是 V17 的增量迁移，初始化版本、修改时间、删除状态及创建标识，增加唯一索引和变更快照表。发现去空格后重名时中止迁移，等待店长确认名称调整，不自动改名或删除。

## 数据与环境收尾

只读检查本地开发库时，Flyway 最高为 V17，套餐表为空且无重名。V18 只在随机集成测试 schema 和本轮浏览器 schema 中执行，未升级业务 schema。集成测试 schema 自动清理；浏览器临时 schema、4 个独立命名空间 Redis key、合成凭证、临时密钥和 Chrome profile 已删除，临时服务与浏览器已停止。

实际启用需要重新启动后端使 V18 生效，并刷新前端。其他环境应先检查重名；如有重名，由店长确认后处理并重试迁移。接口与权限说明见[订单领域说明](../../WuhouCake-order/README.md#套餐填写模板)。

# 员工权限、订单记录与界面验证

## 行为与范围

- 员工和管理员共享日历、录单、订单协作、查询统计及导出。只有员工账号管理与对应身份审计受管理员权限限制。前端订单统计入口不再隐藏给员工，员工停留在员工管理地址时返回工作台；后端仅将两个订单经营查询/导出 GET 路径开放给已改密员工，其他管理接口仍受保护。
- 详情备注区只预览最近三条整单或商品备注。全部备注与操作记录进入独立记录页，左上角返回详情，支持类型筛选及每页 20 条加载。预览和完整记录的缓存键包含页大小，分页按活动 ID 去重；未发布的备注离开前确认。
- 月历中的日期及订单卡片进入对应日期的日工作台；当前地址已经是该日期时也会切回日工作台。周历订单卡片继续进入详情。
- 新密码接受 8–128 个合法 Unicode 码点。管理员既可随机重置，也可通过 PATCH /api/admin/employees/{id}/password 指定其他在职员工的新临时密码；指定密码提交 expectedVersion，过期版本拒绝覆盖。两种操作都会撤销旧凭证并要求员工首次登录改密。明文密码不记录到审计，也不在指定密码响应中回传。
- 使用 impeccable 与 frontend-design 的产品界面指导，保留现有品牌与黄色主操作。精简录单、详情、工作台、统计和员工管理的重复说明，统计口径收纳到折叠说明，减少空备注/图片提示，移除面板淡入，提高文字对比度、当前导航和返回入口辨识度。并发冲突、数据未保存、金额含义等必要提示保留。

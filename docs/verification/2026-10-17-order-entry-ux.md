# 订单录入与查询交互验证

## 字段和查询规则

- 客户订购人是向门店订购商品的客户，可留空；下单员工是员工业绩归属。实际创建及操作员工仍由服务端身份上下文记录。
- plannedHandoffAt 显示为“取货时间”，指客户自提或配送员从门店取走商品的时间。收货日期仍独立决定日历归日；界面、识别候选和订单 XLSX 单据使用相同文案，接口字段保持原名。
- 新建、编辑商品及识别候选共用中文类型下拉框：蛋糕、甜甜圈、纸杯蛋糕、其他茶歇。保存值保持 CAKE、DONUT、CUPCAKE、OTHER；历史特殊类型保留原值，改选后才更新。
- 日期沿用原生控件，完整选择后失焦收起。键盘逐段输入保持焦点，Enter 完成输入，不提交录单表单。
- 订单查询默认按本月录单日期（北京时间）筛选，未来收货的预约单也包含。保留收货日期口径，提供今天录入、本月录入、本月至今收货的快捷入口。查询、分组与导出继续使用同一组已应用条件。
- 日历仍默认今天，并记忆状态及付款筛选。新建成功后及订单详情返回链接定位到该订单的收货日；页面解释日期口径并提供清除记忆筛选的入口。
- 员工初始密码随机生成，没有统一默认值。新增或重置后定位到密码提示，展开后可查看及复制；关闭或离开后不能再次查看，可通过重置生成新密码。

工作区源码内容哈希在整理前后核对，既有文件保持原样；暂存内容来自独立目录，未通过覆盖工作区、stash、reset 或 clean 来拆分修改。当前分支原有未推送的身份授权框架提交 `e9535ba` 是前置基础，会随当前分支一起推送。

## 独立验证

在 HEAD 的干净归档上，仅叠加本次提交候选文件，执行：

~~~sh
rtk npm test --prefix frontend
rtk npm run build --prefix frontend
rtk proxy ./mvnw -B -pl WuhouCake-bootstrap -am -Pintegration '-Dit.test=OrderPackageIT' verify
~~~

结果：72 项前端测试、TypeScript/Vite 构建、287 项后端单元/Web/ArchUnit 检查、7 项套餐真实数据库及 HTTP/SSE 集成测试均通过。数量少于完整工作区的记录，是因为未包含其他未提交功能及其测试。没有重跑完整工作区的全部浏览器验收；此前双账号浏览器结果分别见[套餐浏览器验收](2026-10-25-package-browser-acceptance.md)和[实时同步验证](2026-10-25-package-live-sync.md)，其运行基线为当时完整工作区。

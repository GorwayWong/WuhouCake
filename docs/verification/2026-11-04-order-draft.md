## 复现

在 `frontend` 下启动独立开发服务器：

```sh
npm run dev -- --host 127.0.0.1 --port 5197
```

另一个终端在 `frontend` 下执行：

```sh
node --test tests/orderDraft.browser.mjs
```

需要可用的 Playwright 模块及本机 Chrome。模块不在 Node 解析路径时，通过 `PLAYWRIGHT_MODULE` 传入绝对模块路径；本次复用了环境已有模块，没有修改项目依赖。更多测试参数见 [前端说明](../../frontend/README.md#草稿回归验证)。

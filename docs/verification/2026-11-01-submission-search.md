# 客户填单搜索与摘要布局验证

日期：2026-11-01。仅本地实现，保留此前月历与统计文案改动，未部署线上。

- 客户填单 GET 查询新增可选 keyword、ALL 状态；查询列表和 count 共享同一条件，在数据库分页前过滤。沿用原状态默认值、权限和记录保留规则，不新增数据库字段。
- 前端客户填单定向测试 7 项通过，类型检查通过；后端 CustomerSubmissionServiceTest 3 项及相关模块 ArchUnit 检查通过。
- CustomerSubmissionIT 定向执行 2 项：搜索覆盖原始／更正手机号、连续号码片段、空格短横线、F 前缀和无前缀编号、编号大小写、跨状态、本人／全部客服范围、分页结果与总数、无结果和删除排除；另验证已有正式订单过期清理后的填单保留边界。均在独立测试 schema 中通过，未运行全量集成测试。
- 375px、1280px 浏览器预览验证新关键词跨状态搜索、回车提交、编号命中已确认记录、清除回待确认、详情返回恢复关键词及第 2 页。
- 两种屏宽的统计区域顺序均为尺寸统计→订单明细→员工业绩汇总；员工订单筛选后自动定位明细标题。
- 两行备注测试使用 931 字符和多行内容，展示高度约 38.4px（两行），其余内容截断，页面无横向溢出。浏览器使用真实组件和模拟 API 数据，不创建真实订单，未测试真实手机设备。

# 客户填单批注调整（2026-11-05）

## 需求与实现

按客户图片批注调整公开填单页，图片入口以维护者补充的“客户不能添加图片”为准。

- 客户不再选择商品类型、填写商品名称；新项仍提交 `CAKE` 和“蛋糕”。员工核对继续支持原有品类和名称更正。
- 字段依次为尺寸（寸）/数量、内胚/奶油、夹心馅料、祝福语、其他要求。360px 及以上保留成对字段，320px 单列。
- 内胚默认原味、夹心默认芒果；客户未填奶油时明确提交“原味动物奶油”。员工与直接 API 的原有默认值不变，历史数据不回填。
- 夹心保留文本输入，提示可替换馅料及最多混搭三种，由客服核对，不新增自动拆分或限制任意文本的规则。
- 多商品添加、移除与尺寸必填保留。客户页面无图片控件，提交内容无图片字段。
- 提交按钮前完整展示维护者提供的正式“订购需知”，餐具份数用表格展示。不增加支付、运费计算或强制勾选。

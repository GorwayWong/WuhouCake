# UI 说明文字精简验证

## 范围与原则

精简工作台、订单详情、录单与编辑、付款明细、查询统计、客户填单、二维码、员工管理、识别辅助及导出中的系统说明。
只删除和改写，不新增帮助入口、提示气泡或折叠功能；保留字段标签、业务数据、备注与审计、权限、必填标识及异常保护。

## 主要变更

- 工作台删除重复介绍，保留“全天出货订单，不含取消”；付款汇总以日期、付款时间、订单总额和笔数表达功能及口径。
- 蛋糕胚统计保留尺寸小计与口味数量，移除抄单用途说明。
- 详情删除常驻制作教程；仅当完成操作受商品完成状态阻挡时提示剩余未完成数量。普通保存反馈缩短，制作节点重置等后果仍显示。
- 录单和编辑保留未报价、零元及付款状态含义；并发冲突、结果未确认、上传和提交防重复提示仍在相应状态出现。
- 查询统计明确整单金额列名，删除重复介绍和滑动表格教程。保留既有统计口径及无数据反馈。
- 客户提交确认、二维码重置后果、密码只显示一次、第三方识别的数据发送告知仍保留。
- 仅移除因此不再使用的说明 CSS，未全局隐藏帮助文字。

## 验证结果

- PASS：前端 TypeScript / Vite 构建。
- GAP：前端全量测试 89 项，通过 88 项。唯一失败为既有商品类型测试预期旧类型集合，与本次文案精简无关，未调整。
- PASS：真实 Chrome 的桌面及窄屏检查覆盖工作台、订单详情、录单、查询统计和客户填单，未发现页面横向溢出。
- PASS：独立金额表单保留“留空为未报价，0 为零元。付款状态不变。”；取消编辑后返回正常详情。录单保留联系电话标签、金额规则及创建按钮，已删除默认状态说明。
- PASS：真实局域网客户填写页正常打开，手机宽度保留明确必填字段和“提交后待客服确认”。
- 本轮浏览器检查未提交订单、填单或其他业务写入。错误、并发冲突和第三方调用确认通过代码检查保留，未刻意制造网络故障或调用第三方模型。
- 未修改后端 API、数据库、权限或状态流转，无需后端回归或数据库迁移。

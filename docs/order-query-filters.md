# 订单查询与统计筛选

## 页面布局

展开筛选后，“日期口径”独占一行，其后依次显示四组双列字段：开始日期／结束日期（含当天）、订单状态／付款状态、配送或自提／蛋糕尺寸（寸）、下单方式／客户电话。“商品名称”独占下一行，最后显示未归属、包含取消和查询按钮。360px 及以上保持双列，更窄屏幕使用单列；布局规则仅作用于订单查询页。

客户／电话支持订单号、客户姓名和联系电话。商品名称是独立条件，与客户关键词及其他筛选条件取交集。编辑后点击“查询”才生效，并回到第一页；进入详情后返回保留条件和页码。“清除筛选”清除商品名称和其他普通条件，保留已经查询的日期范围、日期口径及删除模式。

顶部汇总仅展示“匹配订单”和“订单总额”，不展示匹配商品总件数及蛋糕总个数。其下保留日期范围、日期口径、已付款／未付款订单总额、未报价提醒与统计口径说明；尺寸统计、订单明细、员工业绩及 Excel 中的商品数量继续保留。

## 下单方式

下单方式使用已有 `orderingMethod` 字段，与员工归属、配送／自提和客户填单来源分开保存。“下单人”在此处是固定渠道名称，不是员工姓名。查询页原员工选择框替换为下单方式，员工归属字段、员工业绩及员工下钻继续保留；“仅未归属订单”仍筛选未归属员工的订单。

查询、新建及编辑共用“下单人、小程序、到店、客服号”四个常用选项。选择“其他”后填写具体文字，不能为空；仅保存实际文字，不保存界面选项标识。录入允许“未填写”，查询默认“全部”。文字去除首尾空白，最多 80 字符；历史自由文本在编辑时显示“其他＋原值”，不自动重分类。

渠道由员工手动填写，扫码填单确认不会自动写入“小程序”。旧客户端仍可提交任意合法自由文本。没有新增数据库字段、迁移或历史数据回填。

三个管理查询／导出接口同时支持可选 `orderingMethod`（GET 查询参数或 ZIP JSON 字段），省略或空白不筛选，超过 80 字符返回 400。使用去除首尾空白后的完整文字匹配，区分英文字母大小写，特殊字符按字面处理；与客户关键词、商品名称、尺寸等取交集，在分页和聚合前筛选。列表、金额、分组、Excel 和 ZIP 共用同一条件，汇总 Excel 的统计页记录该条件，ZIP 保留所选订单的完整内容。

编辑条件后查询生效并回到第一页，详情返回保留条件；清除筛选同步清除下单方式。历史未付款快捷模式忽略该条件，编辑下单方式会退出快捷模式。已删除订单查询同样支持该条件。

## 商品匹配与金额

- 商品名称按字面连续片段匹配，区分英文字母大小写；去除首尾空白，最多 100 字符。空值不筛选，`%`、`_`、引号和反斜杠均作为普通文字。
- 名称与尺寸必须同时匹配同一件未移除商品；尺寸筛选仅匹配蛋糕。没有匹配商品的订单被排除，筛选在分页之前完成。
- 商品摘要、匹配商品数量、蛋糕数量、尺寸分组及员工业绩中的商品数量，仅使用匹配商品。
- 订单数按订单去重，金额始终使用匹配订单的完整约定金额，不按商品分摊，也不因同单匹配多个商品重复计算。付款金额沿用当前付款状态，不代表实收。
- 列表商品品类继续展示订单中全部未移除商品的分类，不随名称和尺寸筛选裁剪。

例如，一单包含八寸草莓蛋糕 2 个和十寸巧克力蛋糕 1 个，整单金额 520 元。筛选“草莓”后，顶部显示匹配订单 1 单、订单总额 520 元；订单明细仍显示匹配 2 件、其中蛋糕 2 个，八寸分组为 2 个；同时筛选十寸时，该订单不匹配。

## 接口与导出

以下接口增加可选字符串 `productName`，省略参数保持原行为：

| 接口 | 参数位置 | 行为 |
| --- | --- | --- |
| `GET /api/admin/orders` | 查询参数 | 订单、总数和分组共用商品匹配条件 |
| `GET /api/admin/orders/export` | 查询参数 | 汇总 Excel 的商品明细仅包含匹配商品；统计页记录商品名称条件 |
| `POST /api/admin/orders/exports/zip` | JSON 请求体 | 按条件选取订单，每份逐单 Excel 保留完整订单商品 |

`productName` 超过长度限制返回 400。既有权限、日期范围限制、导出数量限制及取消订单规则保持不变，无数据库迁移。已删除订单同样支持名称筛选，继续遵循删除日期与保留期限制。

“所有历史未付款”模式继续忽略普通筛选，包括商品名称；编辑任一普通条件会退出该模式，点击查询后按日期范围和当前条件执行。

## 验证

前端回归覆盖旧视图无新字段、参数规范化、长度限制和历史未付款模式。浏览器回归 `frontend/tests/managementFilters.browser.mjs` 覆盖 320px／360px／390px／1280px 布局、日期与选择弹层、组合筛选、查询后生效、分页、详情返回、清除及两个导出请求。

后端 `ManagementFilterTest` 验证字段约束；`WorkflowManagementIT` 的 `productName*` 用例通过独立 PostgreSQL schema 和 Redis 命名空间验证真实 HTTP 查询、聚合、Excel 内容、ZIP 完整商品、特殊字符、移除商品、删除订单及旧参数兼容。
